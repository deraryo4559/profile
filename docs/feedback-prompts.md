# Feedback / Design Prompts

## Claude Chromeに見てもらうためのプロンプト

```text
あなたはWebデザイン、UX、ポートフォリオ設計、フロントエンド実装レビューに強いレビュアーです。
以下のプロフィールサイトをChromeで実際に見ながら、改善フィードバックをください。

対象サイト:
https://ryo-onodera.com/profile/

前提:
- Ryo Onodera / 小野寺 諒の公式プロフィールサイトです。
- 作品集そのものではなく、人物理解、経歴確認、撮影・AI/開発・研究支援の相談導線、外部リンクをまとめるプロフィールハブです。
- 技術スタックは Vite / React / TypeScript / Tailwind CSS です。
- デザイン方針は、白基調、太いタイポグラフィ、青・緑・黄・ピンクのアクセント、商業的で信頼感のあるプロフィールサイトです。
- 学生らしい親しみやすさは残しつつ、軽すぎるステッカー感やAIっぽい過剰な装飾は避けたいです。

重点的に見てほしい観点:
1. ファーストビューで「何者か」「何を相談できるか」が5秒以内に伝わるか
2. Profile / WORK / NEWS / LINK / Contact の情報設計が迷いにくいか
3. WORKカードとNEWS一覧が、実績として信頼できる見え方になっているか
4. ACES Internship、松尾研寄附講座、GitHub公開リポジトリ、撮影活動の個別ページが、プロフィール補足として十分か
5. Contactページのフォーム項目が、相談する人にとって入力しやすいか
6. PC / モバイルで文字、ボタン、カード、画像の詰まりや読みづらさがないか
7. 参考サイト doisena.jp のような清潔感・編集感に近づけるには、どこを磨くべきか
8. 採用担当、撮影依頼者、AI/開発相談者、研究関係者の視点で不足している情報は何か

出力形式:
- 最初に総評を5行以内で書いてください。
- 次に「優先度 高 / 中 / 低」に分けて改善点を箇条書きにしてください。
- 各改善点には、理由と具体的な修正案を添えてください。
- 可能なら、ページ別に「トップ」「WORK」「NEWS」「Profile詳細」「Contact」「モバイル」の観点も分けてください。
- 良い点も最後に3つ挙げてください。
```

## デザイン案を画像生成するためのプロンプト

```text
Ryo Onodera / 小野寺 諒のプロフィールサイトを、現在のデザイン方針をベースにさらにブラッシュアップしたWebデザインモックアップとして生成してください。

目的:
人物理解、撮影・AI/開発・研究支援の相談、実績確認、外部リンクへの回遊ができる公式プロフィールハブのデザイン案を作る。

サイトの方向性:
- 白基調で清潔感がある
- モダンで商業的、信頼感がある
- 太い英字タイポグラフィと読みやすい日本語本文
- 青を主軸に、緑・黄色・ピンクを小さなアクセントとして使う
- 写真、WORKカード、NEWSリスト、Contactフォームが主役
- 学生らしい親しみやすさは少し残すが、子どもっぽくしない
- AIらしい発光、紫グラデーション、3D未来感、ステッカー過多、手描き過多は禁止

生成してほしい画面:
PC幅の縦長Webサイトモックアップを1枚で生成してください。
構成は上から以下:
1. Sticky header: ROロゴ / PROFILE / WORK / NEWS / LINK / CONTACT
2. Profile hero: 左に大きな名前、肩書き、短い本文、CTA。右に斜めトリミングのプロフィール写真エリアと青い幾何学アクセント。
3. 経歴ハイライト: ACES Internship, 松尾研寄附講座 修了, GitHub公開リポジトリ, 撮影活動。4つのクリック可能な小さなナビゲーションとして見せる。
4. WORK: Photography / AI Software / Research の3カテゴリ。写真付きカードを2件ずつ程度。
5. NEWS: 罫線ベースのニュース一覧。カテゴリラベルと日付を見やすく。
6. LINK: Portfolio, GitHub, Laboratory, Instagram, LinkedIn のリンクカード。
7. Contact CTA: 緑の横長CTAまたは清潔な問い合わせ導線。

デザインの改善ポイント:
- 現状より余白と行間を整え、より上質に見せる
- WORKカードの画像比率と見出しの密度を揃える
- Contactページにつながる導線を自然に強くする
- ボタンやタグは角丸を小さめにし、業務用サイトらしくする
- 下層ページにも展開できる統一感を出す

禁止:
- 文字が読めないほど小さいUI
- 架空の企業ロゴ、実在企業ロゴ、透かし
- 過剰なイラスト、キャラクター、ステッカー
- 紫や青紫の派手なグラデーション
- 暗いサイバー風、SF風、3Dホログラム風
- ランディングページ風の過剰なヒーロー演出

出力:
Figmaで作ったような、実装可能で洗練されたPC表示のWebデザインモックアップ。実際のWebサイト改善に使えるレイアウトとして生成してください。
```
